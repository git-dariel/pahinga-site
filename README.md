<h1 align="center">Pahinga</h1>

<p align="center">Work well. Rest well.</p>

---

Pahinga is a calm desktop companion for Windows that helps you take breaks, drink water, and move during long computer sessions. It lives in your system tray and speaks up only when it matters.

## Features

- **Focus timer** — 25-minute work blocks with intentional breaks
- **Hydration nudges** — sip-of-water reminders on your schedule
- **Guided stretches** — neck, shoulder, wrist, and 20-20-20 eye routines
- **Rest-lock mode** — full-screen overlay for when you need an actual pause
- **Daily summary** — a quiet end-of-day reflection with no streak pressure
- **Tray-quiet by default** — no popups, no audio, just a steady green dot

## Running the site locally

The landing page is a single static HTML file with no build step required.

```bash
# Clone the repo
git clone https://github.com/git-dariel/pahinga-site.git
cd pahinga-site

# Open in browser
start index.html
```

Or serve it with any static file server:

```bash
npx serve .
```

## Stack

Plain HTML, CSS, and vanilla JavaScript. No frameworks, no dependencies, no build tools.
